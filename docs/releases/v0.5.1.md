# Daisywheel REAmade v0.5.1

v0.5.1 makes controller-only settings navigation visible and reliable in the
non-activating overlay used by KDE, and removes the now-unneeded Minimal mode.

## What's new

- Keep an explicit controller selection while navigating settings. This works
  even when the overlay does not own desktop keyboard focus.
- Highlight the selected setting, Help button, or Back to keyboard button, and
  show its name with a concise controller guide on the settings screen.
- Use D-pad up/down to move between available controls, left/right to change
  sliders and options, A/Start to toggle or activate, LB/RB to switch tabs, and
  B to return to the keyboard. A, B, or Start also closes the Help panel.
- Increase the controller adjustment step for pointer speed, opacity, sound
  volume and haptic strength so those settings are practical to change from a
  controller.
- Remove Minimal mode and its toggle. The regular window now provides the
  controls needed for moving, resizing and configuring Daisywheel.
