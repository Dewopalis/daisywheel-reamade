# Daisywheel REAmade v0.5.0

v0.5.0 makes the living-room controller workflow more complete, adding
controller-only settings navigation, text cursor editing and configurable stick
deadzones.

## What's new

- Hold the configured controller shortcut to open Settings. Navigate with the
  D-pad, adjust controls with left/right, activate with A or Start, switch tabs
  with LB/RB, and return to the keyboard with B.
- The wheel labels the hold action and shows progress while the shortcut is held,
  with a confirmation sound when the Settings action is ready.
- New installations use the Living room / desktop controller profile by
  default. Existing profile choices and other saved preferences are preserved.
- Hold RT and move the left stick to move the text cursor. Hold LB to select,
  RB to move by words, or both to select by words.
- Adjust the shared stick deadzone from 5% to 45% for wheel selection, pointer
  movement and text editing.
- Settings controls now fit narrow windows without a horizontal scrollbar.
- Extract the overlay drag, resize, touch activation and wheel rendering widgets
  from `main.cpp` into a separate UI module.

## Validation

- Linux CMake build passed.
- CTest passed both the wheel-selection and overlay-placement tests.
- The tagged GitHub Actions workflow builds and tests the Windows installer and
  portable ZIP, Debian package and AppImage, and Fedora RPM before attaching
  them and `SHA256SUMS.txt` to the draft release.

## Known limitations

- KDE portal permission prompts are external dialogs; controller-only
  interaction with those prompts still needs testing.
- Cursor editing and selection should be checked in target applications on
  Windows and KDE Plasma / Wayland. Text-field behavior can vary by application.
- Steam Deck Gaming Mode, touchscreen activation on target devices and a wider
  range of controllers still need validation.
