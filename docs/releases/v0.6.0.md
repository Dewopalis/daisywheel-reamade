# Daisywheel REAmade v0.6.0

v0.6.0 adds extended and user-imported character layouts for typing characters
that are not available in the standard wheel.

## What's changed

- Add a built-in extended special characters layout with additional accented
  characters and punctuation.
- Import and export editable UTF-8 text layout files. Daisywheel validates the
  format before applying a layout and supports up to eight saved custom layouts.
- Select and remove custom layouts in Controller settings. Importing a layout
  with the same name replaces the saved version.
- Migrate the previously saved single imported layout into the new multi-layout
  collection.
- Add layout editing instructions to Help and document the file format.
- Clear layout import, export, and removal status messages automatically.

## Validation

The pull request passed Windows, macOS, Debian/AppImage, and Fedora RPM build,
test, and packaging checks. The tagged release workflow repeats platform checks
before preparing release packages.

## Known limitations

- macOS remains experimental and has not been validated on physical hardware.
- Steam Deck Gaming Mode and broader handheld compatibility remain unverified.
- Layout files support one Unicode code point per slot; combining-character
  sequences are not supported.
