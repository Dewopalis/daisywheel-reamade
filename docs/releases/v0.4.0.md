# Daisywheel REAmade v0.4.0

v0.4.0 adds configurable controller navigation and optional synthesized sound
feedback on top of the v0.3.1 mouse-input reliability fixes.

## What's new

- Configure the controller button used to show and hide Daisywheel.
- Adjust scroll direction for living-room mouse mode.
- Keep keyboard controls and settings together in the main window.
- Enable or disable MIDI-pitched petal and button cues, adjust their volume, and
  preview either sound in settings.
- Reduce the default sound output so the cues remain subtle. Previously saved
  quiet sound levels are migrated to preserve their perceived volume.

## Validation

The package workflow passed its Windows, Debian DEB/AppImage and Fedora RPM
jobs. CI builds and tests the app, installs the DEB and RPM packages, checks
their startup, smoke-tests the staged Windows package, and launches the extracted
AppImage. The v0.4.0 tag reruns these checks before attaching packages and
`SHA256SUMS.txt` to the draft release.

## Known limitations

- Package smoke tests do not replace testing on handheld PCs and living-room
  systems. Controller behavior, audio levels and text-field detection should
  still be checked on target hardware.
- KDE Plasma on Wayland is the supported Linux system-keyboard backend; other
  Linux desktops and Steam Deck Gaming Mode are not supported yet.
- This release does not add controller-driven text cursor navigation or
  selection.
